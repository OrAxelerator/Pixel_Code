> [!NOTE]
>
> Keyboard shortcuts:
> 
> * **SPACE**: show/hide full view on a project
> * **q**: stop the execution of the tui
> * **↑/↓**: navigation
> * **/** : Search a project by name
> * **c** : quit rescearch
> * **f** : sort project by status (all / done / todo)
> * **p**: open settings
> * **e**: edit project data from Pixel_Code
> * **a**: add a project
> * **d**: delete a project
> **m**: marked a project done/todo
