# Keyboard shortcuts

### Main screen

| Key | Action |
| --- | --- |
| **↑/↓** | navigation |
| **ENTER** | open the selected project with your editor (``editor`` setting: VS Code, vim or a terminal) |
| **SPACE** | show/hide the detail panel of a project |
| **/** | search a project by name |
| **c** | clear the search |
| **f** | filter projects by status (all / done / to finish) |
| **m** | mark the project as done / to finish |
| **a** | add a project |
| **e** | edit the data of a project |
| **d** | delete a project (from Pixel_Code only, your files are not deleted) |
| **p** | open the settings |
| **g** | github actions (not available yet) |
| **q** | quit Pixel_Code |

### Settings screen

| Key | Action |
| --- | --- |
| **↑/↓** | navigation |
| **SPACE** | change the value of the setting |
| **p** | save and go back to the main screen |
| **q** | quit Pixel_Code |

### Text inputs (add / edit / search)

Type the text then press **ENTER** to validate.
